Monitoramento de Rede

Acompanhe computadores e impressoras reportados pela central JFS Connect.

Serviço Cloudflare disponível

Aguardando os primeiros relatórios

O serviço está publicado. Os dispositivos aparecerão após a configuração do Connect Windows e o primeiro envio autorizado.

Os dados são recebidos somente dos monitores autorizados; nenhum computador da rede é acessado diretamente pelo site.

JFS Connect v2 — Monitoramento direto

O Monitor Windows agora pode enviar informações para este site sem precisar do Connect Windows intermediário. Cada computador tem identificação e permissões próprias, com reparos desligados até serem liberados nele.

Código de vínculo temporário — válido por 5 minutos. Insira em JFS Monitor → Configurar → Conexão direta ao site.

Entre com Google para consultar os Monitores.
Aguardando inventário

Histórico de eventos e reparos

Os reparos são enviados somente ao computador escolhido; exigem autorização naquele Monitor e confirmação do nome no site. Limpar filas e reiniciar o Spooler pode afetar impressões em andamento. Não use em equipamentos de produção sem autorização.

Conexão com a centralNão configurado

Serviço JFS Cloudflare pré-configurado. Entre com uma conta Google autorizada e clique em Atualizar para consultar os relatórios. O segredo de envio fica somente no Windows.

O endereço oficial é preenchido automaticamente. A consulta é somente leitura e não altera computadores ou impressoras.
Como conectar o Monitor ao site?

1. Instale o JFS Monitor em cada computador autorizado e configure o IP e a chave da central Windows. A lista de impressoras será recebida pelo JFS Connect.

2. O serviço JFS Network Telemetry já foi publicado na conta Cloudflare JFS-Connect. A leitura exige sessão Google com e-mail do proprietário verificado ou UID explicitamente autorizado. O celular utiliza o relay separado.

3. No JFS Connect Windows, abra Configurar envio ao site, cole o token privado disponibilizado ao proprietário e confirme a autorização de envio somente depois de validá-la para os equipamentos usados. A Cloudflare já guarda o hash correspondente.

Compartilhamento: o link público pode ser enviado a outro dispositivo, mas não concede acesso aos dados. Cada usuário precisa ser autorizado no serviço e autenticar-se com Google. Não compartilhe o token de envio.
